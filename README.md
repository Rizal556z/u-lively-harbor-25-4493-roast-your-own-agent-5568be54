## What it does

`main.py` (pure Python standard library, no dependencies) writes a single
line to `/output/entry.txt` — a roast of the very agent that wrote it:

> My agent nods at everything I say, calls three tools that go nowhere, then confidently ships the wrong answer with a caveat attached.

The line is 133 characters, one line, inside the competition's 1–140
character gate. It roasts the entrant's own agent on three behaviours the
judge brief names: eager agreement, tool calls that go nowhere, and
confident wrong answers wrapped in caveats.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
